# Go 语言并发之道

本专题记录《Go语言并发之道》的学习过程，重点理解 goroutine、channel、上下文取消和共享内存之间的边界。示例会在现代 Go 版本中验证，并说明调度器与运行时行为对结论的影响。

## 建议记录维度

- **并发模型**：任务拆分、通信方式、所有权与生命周期。
- **同步与安全**：`sync` 原语、竞态条件、死锁与数据一致性。
- **取消与收尾**：`context`、超时、背压、关闭 channel 和 goroutine 泄漏。
- **可观测性与性能**：`-race`、pprof、基准测试及调度开销。
- **实践复盘**：并发代码的失败案例、修复过程和适用场景。
