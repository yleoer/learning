# 图解系统

本专题以《图解系统》为主线，建立从硬件、操作系统内核到应用程序的整体心智模型。抽象概念会配合流程图、实验和操作系统文档，逐步补齐细节。

## 建议记录维度

- **核心抽象**：进程、线程、虚拟内存、文件与设备。
- **运行机制**：系统调用、上下文切换、调度、中断和 I/O 路径。
- **资源管理**：CPU、内存、磁盘和网络资源的分配与隔离。
- **并发与安全**：同步、死锁、权限、隔离及常见故障。
- **实验与图示**：用命令、代码或可视化验证关键结论。
