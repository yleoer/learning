# 图解网络

本专题整理《图解网络》的网络基础与协议实践，沿着一次请求从应用层到链路层的路径理解数据如何传输。涉及协议细节时，会注明 RFC、操作系统和工具版本。

## 建议记录维度

- **分层与协议**：应用层、传输层、网络层和链路层的职责边界。
- **连接生命周期**：DNS、TCP/QUIC、TLS、HTTP 的建立、复用与关闭。
- **寻址与转发**：IP、路由、ARP/NDP、NAT 及常见网络拓扑。
- **可靠性与性能**：拥塞控制、丢包、延迟、吞吐和队头阻塞。
- **抓包与排障**：使用 Wireshark、`tcpdump`、`curl` 等工具验证推理。
