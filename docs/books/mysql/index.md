# MySQL 是怎样运行的

本专题通过《MySQL是怎样运行的》理解 MySQL 从连接、解析、优化到执行和持久化的完整链路。记录会注明 MySQL 版本与存储引擎，避免把特定实现误当成通用 SQL 规则。

## 建议记录维度

- **执行链路**：SQL 解析、优化器决策、执行计划与结果返回。
- **存储与索引**：InnoDB 页、B+Tree、聚簇索引、回表和覆盖索引。
- **事务与并发**：ACID、MVCC、锁、隔离级别与日志协作。
- **性能诊断**：`EXPLAIN`、慢查询、统计信息和可复现实验。
- **版本与场景**：MySQL 版本差异、参数影响及生产中的取舍。
